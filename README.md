# Personal Expense Calculator

## 📌 Description

Personal Expense Calculator is a simple and user-friendly web application developed using **HTML, CSS, and JavaScript**. It helps users manage their income and expenses, categorize spending, calculate total expenses and savings, and view a summary report.

## ✨ Features

* 💰 Add income details
* 💳 Add expense details
* 📂 Categorize expenses
* 📊 Calculate total income
* 💸 Calculate total expenses
* 💵 Calculate savings
* 📋 Display summary report
* 📱 Responsive design
* ✅ Input validation

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Calculations, functions, loops, conditions, and DOM manipulation

## 📂 Project Structure

```text
Personal-Expense-Calculator/
│
└── index.html
```

The project is implemented as a **single HTML file** containing HTML, CSS, and JavaScript.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Enter your income and expenses.
5. Click **Add Income** or **Add Expense**.
6. View your savings and category-wise expense summary.
